Conversor de Temperaturas em C

Este é um projeto simples, leve e eficiente desenvolvido em **Linguagem C** que funciona como uma calculadora interativa de conversão de temperaturas. O programa permite alternar facilmente entre as três principais escalas termométricas do mercado científico e cotidiano: Celsius (°C), Fahrenheit (°F) e Kelvin (K).

Funcionalidades:

O programa suporta as seguintes conversões bidirecionais:
* Celsius ➔ Fahrenheit e Kelvin
* Fahrenheit ➔ Celsius e Kelvin
* Kelvin ➔ Celsius e Fahrenheit
* Interface limpa, intuitiva e baseada em texto (CLI) via terminal.
* Validação de entrada para opções inválidas.
